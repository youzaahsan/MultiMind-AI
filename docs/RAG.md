# MultiMind AI — Retrieval-Augmented Generation (RAG) System

MultiMind AI implements a production-grade multimodal RAG pipeline engineered to eliminate hallucinations, enforce exact source grounding, and preserve document structural integrity.

---

## 1. End-to-End RAG Architecture

```mermaid
flowchart LR
    Doc[Uploaded Document] --> Chunker[Intelligent Semantic Chunker]
    Chunker -->|Metadata + Text Chunks| Embedder[Embedding Service]
    Embedder -->|384-d Dense Vectors| VectorDB[(Vector Store)]
    
    Query[User Query] --> Preproc[Query Preprocessor]
    Preproc --> QEmbed[Query Embedding]
    QEmbed --> Search[Cosine Similarity Search]
    VectorDB --> Search
    Search --> Candidates[Top-8 Candidates]
    Candidates --> Rerank[Hybrid Reranker Dense + Lexical]
    Rerank --> Context[Structured Grounded Context]
    Context --> LLM[LLM Reasoning Engine]
    LLM --> Answer[Grounded Answer + Citations]
```

---

## 2. Intelligent Chunking Methodology (`app/rag/chunking.py`)

Unlike primitive recursive text splitters that blindly slice across sentences and tables, MultiMind AI uses **boundary-aware intelligent chunking**:

* **Heading & Paragraph Preservation:** Splits text along natural `\n\n` paragraph boundaries.
* **Heading Propagation:** Identifies section and chapter headings (e.g. `Chapter 2: Neural Networks`) and propagates them as `section` metadata across all descendant chunks.
* **Page Boundary Tracking:** Maintains exact page numbers from PDF and document inputs (`page_number: 12`).
* **Table Isolation:** Tabular blocks and markdown tables are encapsulated into dedicated chunks with `modality: "table"`.
* **Configurable Window & Overlap:** Defaults to `CHUNK_SIZE=600` words with `CHUNK_OVERLAP=100` words.

---

## 3. Semantic Embeddings (`app/rag/embeddings.py`)

The platform supports dual embedding backends:
1. **Deterministic Semantic Feature Projection (Default / Offline):**
   * Projects word tokens, n-grams, and character bigrams into a 384-dimensional dense feature space with signed hashing and logarithmic frequency scaling.
   * L2 normalized so that identical texts yield cosine similarity $1.0$, and semantically related documents yield strong positive similarity ($>0.5$).
   * Requires **zero network access, zero API keys, and zero download latency**.
2. **OpenAI Text Embeddings:**
   * Uses `text-embedding-3-small` via authenticated REST calls when an OpenAI API key is configured.

---

## 4. Vector Store & Hybrid Reranker

* **Vector Store (`app/rag/vector_store.py`):** Efficient in-memory matrix dot-product cosine similarity search with disk persistence (`data/vector_store/index.json` and `vectors.npy`). Supports metadata filtering by `document_id`, `filename`, or `modality`.
* **Hybrid Reranker (`app/rag/reranker.py`):** Rescores the top retrieved candidates before context construction:
  $$\text{Score}_{\text{hybrid}} = 0.70 \times \text{Score}_{\text{vector}} + 0.20 \times \text{Ratio}_{\text{lexical}} + 0.10 \times \text{Bonus}_{\text{exact\_phrase}}$$

---

## 5. Grounded Citations & Fallback Rules

### Strict Output Directive:
Every answer generated by the RAG system must cite verified sources:
```text
Supervised learning uses labeled training datasets to optimize weights...

Sources:
- machine_learning.pdf — Page 7 (Section: Fundamentals)
- machine_learning.pdf — Page 12 (Section: Training Regimes)
```

### Zero-Hallucination Fallback:
If the user's question cannot be answered using the retrieved document context, the system states:
> *"I could not find this information in the uploaded documents."*
Invented sources and fabricated page numbers are strictly prevented by prompt boundaries and unit tests.
